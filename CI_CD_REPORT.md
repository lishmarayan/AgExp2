# Experiment 4 - CI/CD Pipeline and Prompt-based Automation

## CI/CD Pipeline

A GitHub Actions workflow was configured to automatically:

1. Checkout the repository.
2. Validate Bash scripts using bash -n.
3. Execute the automation script.
4. Display the generated log.
5. Generate a CI/CD report.
6. Upload the report as a workflow artifact.
